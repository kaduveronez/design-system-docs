# Geist Design System

O **Geist Design System** é uma coleção de componentes UI refinados, baseados no **shadcn/ui**, **Tailwind CSS v4** e desenhados para oferecer máxima performance e estética inspirada na Vercel.

## Componentes Disponíveis

- [Button](/docs/button) - Componente principal de ação e disparo de eventos.
