# Gen QRcode Design System

O **Gen QRcode Design System** é a biblioteca oficial de componentes UI, tokens visuais e padrões interativos para todas as aplicações do ecossistema Gen QRcode.

Construído com **Next.js App Router**, **Fumadocs**, **Tailwind CSS v4** e **shadcn/ui**, ele garante consistência visual, acessibilidade e alta performance.

## Mapa do Design System

   - [Cores](/docs/foundations/colors) - Paleta de cores principal `#644a40`, secundária `#ffdfb5`, fundos e Dark Mode.
   - [Tipografia](/docs/foundations/typography) - Escalas de fontes sans, serif e mono.
   - [Iconografia](/docs/foundations/icons) - Ícones Lucide para ações e sinalização.
