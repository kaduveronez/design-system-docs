# Toast & Sonner

Mensagens flutuantes que surgem na tela informando o resultado de uma operação em tempo real.

## Código Manual

```tsx
import { Button } from "@/components/ui/button"
import { toast } from "sonner"

export function ExemploToast() {
  return (
    <Button onClick={() => toast.success("Link copiado com sucesso!")}>
      Copiar Link
    </Button>
  )
}
```
