## Como Usar

Instale o pacote `@phosphor-icons/react` e importe diretamente os ícones desejados:

```tsx
import { QrCode, Sparkle, CheckCircle } from '@phosphor-icons/react'

export function ExemploIcones() {
  return (
    <div className="flex gap-4">
      <QrCode size={24} weight="regular" />
      <Sparkle size={24} weight="fill" />
      <CheckCircle size={24} weight="duotone" />
    </div>
  )
}
```
